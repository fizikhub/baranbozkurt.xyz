# Onboarding & High-Impact Empty States

## Overview
An empty state is not a dead end; it is an educational launchpad. When a user first opens an inbox, folder, or dashboard, zero-data screens must guide them to immediate value.

## The 4 Components of an Actionable Empty State
1. **Contextual Graphic/Illustration**: Friendly, themed visual representation of the concept.
2. **Clear Value Headline**: "No projects created yet".
3. **Educational Subtext**: Explain *why* creating a project helps them achieve their goals.
4. **Primary Call-to-Action (CTA)**: Single high-contrast button ("Create Your First Project") or "Import Sample Template".

## Progressive Onboarding Principles
- **Show, Don't Tell**: Let the user interact with sample data rather than reading a 6-step popover tutorial.
- **Progress Bars**: Show visual completion steps ("Profile 60% complete - 2 steps remaining") leveraging the Goal Gradient Effect.
- **Contextual Tooltips**: Trigger guidance at the moment of intent rather than dumping all instructions upon sign-up.
